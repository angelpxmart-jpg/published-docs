金盛世 JBP 扣款策略與財務認列

2026-08-28

本次討論圍繞金盛世 JBP 合約（133萬含稅）的扣款缺口問題： 4-7月貨款僅 68萬，達成率 38%（目標 176萬）。同時釐清廣告費財務認列性質，並安排與三樓採購（美真）對接前的內部對齊流程。

一、背景脈絡

合約現況

  • 金盛世 JBP 合約金額：133萬（含稅），有效期至 2026 年 12 月底
  • 每月扣款目標：44萬（依合約節奏）
  • 4-7月累計貨款收入：68萬
  • 達成率：68 ÷ 176（4個月目標）= 38.6%，缺口超過 60%

扣款路徑選擇背景 主管會議方向確認：不直接煩三樓（實體採購），改以「轉單貨款慢慢扣」為主。 現有合約已用印，本期可操作；未來無新合約時，JBP 扣款路徑需另行協商。

金盛世業績組成（月均）

來源 說明
箱購（三樓） 主力，業績佔比約七至八成，單價高
JBP 轉單品 品項少，7月才開始有轉單貨款
門市 / 大潤發 少量
月均合計 200-250萬；有檔期可達 300萬

二、核心問題與結構矛盾

問題 1：轉單貨款不足扣款

  • 轉單品項少，線上業績主力仍在箱購（三樓貨款）
  • 廣告投放（7月 55萬、8月 42萬）覆蓋全品，無法只導轉單品
  • 若廣告帶來的轉換落在箱購，扣款歸三樓，JBP 帳面沒有進項

問題 2：折價券與樓下毛利衝突

  • 線上折價券若適用箱購，會被樓下認為影響單抽售價
  • 現行做法：對外說法為「行銷費用補貼」，認列為全電商營業收入
  • 核心立場：這筆收入不是 Rebate，是正式營業收入（商品銷貨收入），不能拆給三樓

問題 3：廣告費的財務認列尚待確認

  • 廠商扣貨款繳廣告費 = 繳款方式，不影響帳面應付金額
  • 待釐清：三樓採購（美真）是否將廣告費算為毛利減項
    • 若是 → 她會盯緊廣告費用途，甚至要求 Dashboard 進入採購端查看
    • 若否 → 問題不大
  • 折價券 / 點數的認列問題比廣告費更具爭議，需優先釐清

三、具體情境還原

廣告投放 vs 扣款路徑的矛盾

全電商投廣告進來 → 消費者線上購買 → 業績由兩部分組成（JBP 轉單 + 舊商模箱購） → 箱購貨款在三樓，轉單貨款在全電商（可扣 JBP 費用） → 只要廠商認同「透過全電商交易的都算」，Dashboard 報表也這樣抓

金盛世 Dashboard 最複雜，因為有三個業績來源：箱購 + 轉單 + 門市/大潤發

與美真溝通的核心說法

「線下的貨款裡面有一部分是線上的貢獻。我們收的錢不是 Rebate，是正式的商品銷貨收入， 所以無法拆給你。若折價券吃掉費用，我們可以自行出折價券那一包、把錢補貼算回去給你。」

四、其他 JBP 廠商狀況

廠商 狀況
金盛世 扣款缺口大（38%），廣告已花 102萬含稅（廣告+KOL），本次討論主角
跨境豐收 有足夠貨款，可先開立一張付款
齊偉 匯款制（360萬），月營業額從 80萬掉至 10幾萬，合約剛用印，尚未展開執行

齊偉建議方向：LINE Data 合作撈受眾 → 封閉折價券 → 不公開破壞市場價格（同 Momo 模式）

三大合約共同條款：解除條款

  • 若至 2027年2月底未達合約業績目標（如 8000萬），無償補三個月業績
  • 三個月仍未達 → 合約終止，不再補償
  • 老闆不會讓事情走到這一步，需要聽到具體對策

五、核心決策

議題 結論
扣款路徑 以轉單貨款慢扣為主，不再另行煩三樓
廠商/三樓議題拆分 不合併談，金盛世和其他廠商的扣款路徑問題分開處理
財務認列立場 收入認列為正式營業收入，非 Rebate，不可拆分
溝通版本確認順序 內部 Carry → 特助 Paris → 三樓採購美真
金盛世當 Pilot 先以金盛世這個案子跑通溝通邏輯，再複製到其他 JBP
